开屏广告清理

Sileo 源 · SplashAdKiller

添加源

在 Sileo 里打开 软件源 → 编辑 → 添加，输入：

https://darenni86-svg.github.io/SplashAdKiller/

刷新后搜索「开屏广告清理」安装即可。

直接下载 deb

  • rootless（Dopamine / palera1n rootless）
  • rootful（unc0ver / Taurine / checkra1n）

分不清就看手机里有没有 /var/jb：有就是 rootless。

安装后

Respring，然后把目标 App 从后台彻底划掉再打开。

默认全开；配置文件在 /var/mobile/Library/Preferences/com.dsh.splashadkiller.plist。
